Hadish Works Manager v5 - Manual backup

1. Open Settings > Export JSON backup.
2. Check the downloaded JSON file in Downloads.
3. Copy it to Google Drive or another device for protection against phone loss.
4. Every 7 days the app shows an in-app reminder (only while open).
5. To restore, open Settings > Import backup JSON and select the saved file.
6. Test restore with sample data before entering business-critical records.

Existing v4 local data on the same browser and origin should remain available. Do not clear browser data.
